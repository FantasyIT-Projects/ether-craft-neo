# 以太工艺（Ether Craft）

一个以**物品运输与槽位摆放**为核心的 Minecraft（NeoForge）科技模组。

## 核心特色

- **以太与以太能量**：以太是本模组的基础能源，表现为物品，并可以以物品的形式进行传输。
- **以太适应节点**：核心机器。通过加入各类"插件"（功能 / 特性 / 升级）后才能生产或使用以太，执行物流、交通等功能。
- **以太流**：通过发射器插件射出的能量流，同时承担物流与供能——运输以太、携带物品、为镀层装备充能。
- **以太加工中心**：在机器内部按规则拼搭"通道 + 芯片"产线来执行加工配方。
- **镀层系统**：消耗以太粉对装备进行镀层，获得各种特殊效果（如伤害提升、冲刺、伪装、以太流飞行等），与附魔互不冲突。

## 环境要求

- Minecraft 26.1.2
- NeoForge 26.1.2.61-beta
- Java 25
